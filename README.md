# Сборщик проектов

Стартовый шаблон для статических фронтенд-проектов на `Gulp`, `Sass` и `esbuild`.

## Как начать

Проект рассчитан на `Node.js 22` и `npm 10`.

```bash
nvm use
npm ci
```

Если `nvm` не используется, достаточно установить Node 22 вручную и затем выполнить `npm ci`.

## Доступные команды

- Локальная разработка с BrowserSync и сборкой в `dev-server/`:

  ```bash
  npm start
  ```

- Продакшен-сборка в `dist/`:

  ```bash
  npm run build
  ```

- Очистка рабочих директорий:

  ```bash
  npm run clean
  ```

- Проверка проекта:

  ```bash
  npm run lint
  ```

- Автоисправление части замечаний линтеров:

  ```bash
  npm run lint:fix
  ```

- Отдельная сборка стилей:

  ```bash
  npm run styles
  ```

- Отдельная сборка скриптов:

  ```bash
  npm run scripts
  ```

## Как устроен проект

- `source/` содержит исходники проекта.
- `dev-server/` создаётся при `npm start` и используется локальным сервером.
- `dist/` создаётся при `npm run build` и содержит готовую продакшен-сборку.
- HTML собирается из страниц и частей через `gulp-file-include`.
- CSS собирается из `source/styles/styles.scss` в `styles/styles.css`.
- JS собирается через `esbuild`, основной entry point по умолчанию: `source/js/scripts.js`.

## Папки проекта

- `fonts` — шрифты.
- `icons` — SVG-иконки для `stack.svg`.
- `images` — изображения проекта.
- `js` — скрипты и модули.
- `libs` — сторонние библиотеки, подключаемые напрямую.
- `pages` — HTML-страницы.
- `parts` — HTML-части и шаблонные включения.
- `styles` — SCSS-стили.

В основных папках лежат `README.md` с локальными правилами. Если добавляете новую рабочую папку в `source/`, стоит сразу описать её назначение.
