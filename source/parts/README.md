# Папка для HTML-частей

- Здесь лежат общие части страниц, которые подключаются через `@@include`.
- Вложенные папки можно создавать по смыслу: `layout`, `sections`, `modals` и т. п.
- Части именуются с подчёркивания в начале, например `_header.html` или `_footer.html`.

## Правила

1. В `parts` не должно быть полноценных страниц.
2. Если часть используется во многих местах, лучше держать её максимально нейтральной по содержанию.
3. Если часть зависит от конкретной страницы, это стоит явно отразить в названии или в структуре папок.
