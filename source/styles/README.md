# Папка для стилей
`styles.scss` — основной файл подключения всех слоёв стилей сайта.

Папка `base` — базовые стили, глобальные переменные Sass и CSS, шрифты и служебные примеси.

Папки `libs`, `components`, `layout`, `cards` и `sections` подключаются из `styles.scss` по мере необходимости. Если для слоя пока нет файлов, его можно не создавать заранее.

### Правила
1. Все файлы именуем по названию БЭМ блока.
2. Слои подключаются в `styles.scss`, а внутренние файлы слоя — в его собственном `_index.scss`, если это удобно для структуры проекта.
3. Если добавили новый слой стилей, внесите его описание в этот файл.
4. Перед созданием нового слоя проверьте, нет ли уже подходящего по смыслу каталога.
5. Общие правила написания `scss` находятся [здесь](https://github.com/myosminozhka-ru/regulations-for-the-frontend/tree/master).
