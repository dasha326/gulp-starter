# Папка для скриптов

- `scripts.js` — основной entry point, который подключается на страницах.
- Остальные файлы в папке используются как модули или дополнительные entry points, если проекту это действительно нужно.
- Общие утилиты лучше экспортировать из отдельных файлов и импортировать в `scripts.js`, а не вешать на `window`.

## Правила

1. Для нового кода используем ES-модули.
2. Не складываем весь проект в один файл: общий код выносится в отдельные модули.
3. Если подключаете внешнюю библиотеку через `source/libs`, опишите это рядом в коде или в README соответствующей папки.
